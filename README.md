Code repository for:

Robinson AK, Liang J, Saurels BW, Taubert J (2026). Conflict, not category: What the pupil tracks in face pareidolia.

Preprint: https://osf.io/preprints/psyarxiv/wz3r7_v1

300 images of human face, illusory face and matched non-face object stimuli.

Pupillometry measurements in response to these stimuli.
Stimuli were presented centrally at 3.75 Hz, while participants performed an orthogonal target detection task.
